# 玩法试验记录模板

版本：V1.1

日期：2026-11-24

使用状态：模板。未执行的试验只填计划，不填结果。

## 要验证什么

- 试验 ID / 关联规则和决定：待填。
- 体验假设：待填，描述可观察的预期行为。
- 为什么做 / 不验证什么：待填。
- 用户授权的试验范围：待填。
- 事先约定的通过、失败、不确定判据：待用户确认。

## 条件与方法

- 仓库提交、规则版本、配置指纹：待填。
- 参与者、经验、样本数量：待填；没有用户试玩就明确写仅逻辑模拟或纸面推演。
- 固定条件：敌人、种子、规则、时长、配置等，待填。
- 唯一或主要变化因素：待填。
- 操作步骤与记录方式：待填。
- 需要覆盖的正常、边界和失败情形：待填。

| 待填 | 待填 | 待填 | 待填 | 待填 |

## 解释与限制

- 事实：待填。
- 解释/可能的其他原因：待填。
- 反例、样本限制与未覆盖条件：待填。
- 判据结果：通过 / 失败 / 不确定，待填。
- 建议的下一步及成本：待填，尚未自动成为开发决定。
- 需用户判断的问题：待填。
- 用户确认后的处理：待填。
