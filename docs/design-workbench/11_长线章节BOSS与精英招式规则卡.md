## 2. BOSS 与精英通用招式规格框架（适用第 1~N 卷，P-068）

为保证玩家无论玩到第 1 卷还是第 10 卷都能**“一眼读懂招式、靠拼装 + 手操有解”**，所有章节的 BOSS 统一遵循以下四条铁律：

1. **清晰可读结构（P-068）**：
   - **常规关底 BOSS**：固定标配 **「1 个常态招 + 1 个招牌大招（带 `0.7~1.0s` 清晰蓄力/红光前摇预警）+ 1 个生态被动」**；
   - **卷末守门王（如 `1-8`、`2-8`、`N-8`）**：额外拥有 **半血（`50% HP`）二阶段过载变身**，作为该卷的综合构筑与手操检阅官。
2. **标准 4 段动作周期**：
   - `追击/走位` → **`前摇预警 Telegraph（0.70 ~ 1.00s）`**（玩家判断起跳 / `S` 举盾 / `K` 冲刺的黄金窗口）→ **`判定生效 Active`** → **`后摇硬直 Recovery（0.80 ~ 1.60s）`**（玩家贴脸或爆发输出窗口）。
3. **统一高度命中标签（承接 P-009）**：
   - `GROUND`：仅命中地面目标（`y ≤ 0.65m`），**按 `Space` 起跳即可无伤躲避**；
   - `AIR`：仅命中空中目标（`y > 0.65m`），地面走位安全；
   - `BOTH`：空地均可命中，需靠水平走位、`S` 键举盾格挡或 `K` 键冲刺撤出判定区。
4. **空中怪防软锁硬规则（承接 P-064）**：
   - 任何具备常驻浮空或高空盘旋能力的精英/BOSS，每 **`5.0 ~ 6.5s`** 必须执行一次俯冲攻击并进入 **`≥ 1.5s` 的地面硬直窗口**，确保 0 对空零件的纯地面构筑也绝不软锁卡关。

## 3. 第一卷《原初破壳篇》（1-1 ~ 1-8）全量招式规则卡

> *说明：数值倍率均基于 [09](09_数值体系与经济平衡模型.md) §5.1 对应 BOSS 的 `ATK` 基准计算。*

### 3.1 关 1-1：弹跳暴君 · 巨蛙王（教学收官 BOSS）
- **生态被动「高弹后肢」**：移动以小跳为主，受击击退距离减少 `30%`。
- **常态招「黏液泡泡弹」**：中距离向前吐出 1 颗慢速弹道（`0.8× ATK`，标签 `BOTH`，弹速 `5.4m/s`，CD `2.6s`）——教玩家通过跳跃或走位躲避弹道。
- **招牌大招「蓄力高跳砸地」**：
  - 前摇：`0.85s`（原地深蹲鼓腮 + 地面画红色落点圈）；
  - 生效：跃至 `y=2.6m` 后砸落玩家所在位置，产生半径 `3.2m` 地面震波（`1.35× ATK`，标签 **`GROUND`**，CD `5.2s`）；
  - 硬直：落地后喘气 `1.1s`；
  - **核心反制**：看准红圈按 `Space` 起跳完美躲过震波，落地趁硬直狂输出。
- **同关代表精英**：`菜园小刺猬`（近战挨打反弹 `18%` 伤害，教玩家感受反伤）、`跳跳小青蛙`（小幅弹跳 `GROUND` 扑击）。

### 3.2 关 1-2：不动要塞 · 铁背巨龟王（防御与反伤检验）
- **生态被动「硬壳反震」**：正面常态防高（`DEF=12`）；每次缩壳期间反弹 `25%` 近战伤害。
- **常态招「重壳顶撞」**：近身蓄力 `0.45s` 后向前顶撞（`1.0× ATK`，标签 `GROUND`，强击退 `1.8m`，CD `2.4s`）。
- **招牌大招「缩壳滚轮碾压」**：
  - 前摇：`0.90s`（缩进龟壳原地高速空转冒火花）；
  - 生效：沿地面直线高速翻滚 `10m`（`1.45× ATK`，标签 **`GROUND`**，撞到玩家造成击飞，CD `6.0s`）；
  - 硬直：滚至终点急停翻肚皮露出软腹 **`1.5s`**（期间 `DEF` 临时归 `0`！）；
  - **核心反制**：跳起越过翻滚龟壳，等它翻肚皮的 `1.5s` 打满爆发；或携带破甲/施毒零件穿透硬壳。
- **同关代表精英**：`卷球刺猬群`（短距滚刺）、`重壳陆龟`（高防慢速肉盾）。

### 3.3 关 1-3：断颌霸主 · 沼泽巨鳄王（爆发与控距检验）
- **生态被动「嗜血低吼」**：血量低于 `40%` 时移速与攻速提升 `+15%`。
- **常态招「沼泽甩尾」**：贴身时转身横扫（`1.0× ATK`，标签 `GROUND`，击退 `2.2m`，CD `2.5s`）。
- **招牌大招「死亡翻滚突袭」**：
  - 前摇：`0.80s`（大嘴张开超过 90° + 身体贴地蓄力）；
  - 生效：向前突进 `4.5m` 咬合翻滚（`1.65× ATK`，标签 **`GROUND`**，命中附加 2s 减速 `-30%`，CD `5.5s`）；
  - 硬直：扑空或咬完后僵直 `1.2s`；
  - **核心反制**：靠青蛙/弹簧腿垂直起跳越过巨鳄头顶，或用河豚身/大象鼻弹飞打断贴脸节奏。
- **同关代表精英**：`膨胀小河豚`（受击鼓胀弹开玩家）、`横行钳蟹`（带 `50%` 破甲的近战剪钳）。

### 3.4 关 1-4：苍穹裁决者 · 疾风鹰王（立体空战转折 BOSS）
- **生态被动「制空盘旋」**：每 `6.0s` 升空至 `y=2.3m` 盘旋 `3.5s`（仅 `canHitAir` 或空中跳砍可命中）。
- **常态招「高空羽刃」**：盘旋期间朝玩家斜射 2 根羽刃（单根 `0.65× ATK`，标签 `BOTH`，CD `2.2s`）。
- **招牌大招「苍穹俯冲抓击」**（**兼任防软锁落地窗口**）：
  - 前摇：`0.80s`（高空急停亮起金红瞄准激光线）；
  - 生效：沿斜线高速俯冲扑向玩家落点（`1.40× ATK`，标签 `BOTH`，CD `5.8s`）；
  - 硬直：俯冲着陆利爪陷地 **`1.6s`**（强制回归 `y=0` 地面态！）；
  - **核心反制**：有变色龙长舌/炮口/电尾可在空中直接点射；无对空件时看瞄准线横向走位/`K` 冲刺躲俯冲，趁着陆 `1.6s` 硬直集火。
- **同关代表精英**：`疾风蜻蜓`（低空 `y=1.2m` 悬停，周期降落）、`夜袭蝙蝠`（波浪俯冲）。

### 3.5 关 1-5：剧毒冥王 · 幽光巨蝎（异常状态与走位检验）
- **生态被动「幽冥荧光毒」**：所有命中均附加 4 秒中毒（每秒 `2.5%` 玩家 MaxHP 真伤，上限 2 层）。
- **常态招「双钳夹毒刺」**：中近距快戳（`0.9× ATK`，标签 `GROUND`，CD `2.2s`）。
- **招牌大招「荧光致盲 + 弧尾重砸」**：
  - 前摇：`0.85s`（尾部高举发亮蓝绿荧光并伴随短暂地面毒圈预警）；
  - 生效：向前方 `4.0m` 砸落毒尾（`1.35× ATK`，标签 `BOTH`）并在落点留下持续 `4.0s` 的地面毒潭（踩上持续挂毒，CD `6.0s`）；
  - 硬直：拔出尾刺需 `1.0s`；
  - **核心反制**：及时走出毒潭范围，利用毛毛虫回血/三选一「生命汲取」抵消毒伤，或高爆发速杀。
- **同关代表精英**：`潜伏变色龙`（远程对空弹舌）、`断尾壁虎`（残血断尾脱身一次）。

### 3.6 关 1-6：破城重坦 · 裂地犀牛王（动量冲击与举盾检验）
- **生态被动「泰山之躯」**：完全免疫击退与减速。
- **常态招「震地践踏」**：前蹄重踩地面（`1.05× ATK`，半径 `2.8m`，标签 **`GROUND`**，CD `2.6s`）。
- **招牌大招「裂地全图冲锋」**：
  - 前摇：`0.95s`（低头刨土 + 全行红轨警告）；
  - 生效：以 `11.5m/s` 高速贯穿冲锋 `12m`（`1.60× ATK`，标签 **`GROUND`**，强击退 `3.5m` 并无视 `50% DEF`，CD `6.2s`）；
  - 硬直：冲锋急停喘息 `1.3s`；**若被玩家 `S` 键举铁门重盾/雄鹿角完美架挡，立即提前撞停并进入 `1.8s` 晕眩大硬直！**
  - **核心反制**：要么高跳越过头顶，要么用 `S` 键正面盾反赚取巨额输出窗口。
- **同关代表精英**：`疾驰鸵鸟`（极速绕近突袭）、`重踏小象`（抗击退高血前排）。

### 3.7 关 1-7：高压疯魔 · 特斯拉机甲鸡（赛博机械飞升转折 BOSS）
- **生态被动「过载静电环」**：每 `6.5s` 自动劈出一道追踪小电弧（`0.55× ATK`，标签 `BOTH`，可被 `S` 举盾减伤）。
- **常态招「喷气电锯滑斩」**：启动短喷气前滑 `3.5m` 挥锯（`1.1× ATK`，无视 `50% DEF`，标签 `GROUND`，CD `2.8s`）。
- **招牌大招「高压雷柱轰炸」**：
  - 前摇：`0.90s`（地面连续出现 3 个错位蓝白雷击光柱圈，间隔 `0.4s`）；
  - 生效：光柱依次劈下垂直雷电（每道 `1.30× ATK`，标签 **`BOTH`**，CD `6.5s`）；
  - 硬直：雷击结束过热冒烟 `1.4s`；
  - **核心反制**：看到预警圈用移动 + `K` 键冲刺连续走出红圈，再趁过热散热期反打。
- **同关代表精英**：`暴走弹簧球`（高频连跳砸地）、`铁盾守卫`（周期举盾减伤，需破甲或绕背）。

### 3.8 关 1-8：第一界域代行者 · 苍穹铁羽暴君鸡（第一卷守门王 · 两阶段）
- **生态被动「机械羽翼混装」**：集结第一卷动物 + 机械代表特征，免受单一小击退打断。
- **一阶段（`100% ~ 50% HP` · 制空炮台形态）**：
  - 常态招「迷你钢炮三连射」：滞空 `y=1.6m` 朝玩家连发 3 枚扇形炮弹（单枚 `0.70× ATK`，标签 `BOTH`，CD `3.0s`）；
  - 大招「轨道轰炸 + 降落散热」：前摇 `0.85s` 发射高爆弹，随后必然降落地面散热 **`1.5s`**（给近战玩家稳定反击期）。
- **半血转阶段（`50% HP`）**：触发 `1.2s` 过载爆发震退（无伤害），蛋壳 0 号大喊“警告！这家伙进入二阶段狂暴了！”
- **二阶段（`50% ~ 0% HP` · 火箭头槌狂暴形态）**：
  - 常态招「喷气锯斩连击」：高频压近斩击（`1.05× ATK`，标签 `GROUND`，CD `2.1s`）；
  - 终极招牌大招「苍穹火箭头槌」：前摇 `0.85s` 升空蓄力锁定 → 高速斜冲撞击地面（`1.75× ATK`，标签 `BOTH`）并引爆半径 `3.8m` 地面震波（`1.1× ATK`，标签 `GROUND`，CD `6.0s`）→ 撞击后机体过载僵直 **`1.5s`**。
- **击败揭幕**：播放 30 秒章末暗线求救乱码（见 `06` §5.3），正式解锁**「巴别无尽深渊」「每周狂想变异赛」**，并开启通往**第二卷《深渊暗海界》**的长线入口！

## 4. 后续第 2~N 卷持续更新 BOSS 通用制作模板（长线无限扩展，P-046, P-067）

巴别进化巨塔**没有关卡终点**。后续每开发 1 个新生态大卷（每卷 8 关、持续更新），所有新 BOSS 均按以下标准规格直接填表入库，**零代码架构重写**：

### 4.1 新卷 BOSS 标准字段模板
| 必填字段 | 规则要求 | 验收红线 |
|---|---|---|
| `卷号与关号` | 如 `2-1` ~ `2-8`、`3-1` ~ `3-8` ... `N-8` | 每卷末关 `N-8` 固定为两阶段守门王 |
| `生态被动（1条）` | 绑定本卷专属环境机制（如第 2 卷极压水泡/电流、第 3 卷熔岩喷发、第 4 卷微重力） | 不可直接让某类流派 0 输出 |
| `常态招（1招）` | 明确倍率（`0.7~1.1× ATK`）、冷却（`2.0~3.0s`）、命中标签（`GROUND/AIR/BOTH`） | 与大招形成错拍节奏 |
| `招牌大招（1招）` | 必带 `0.70~1.00s` 可读前摇 + 明确克制解法 + `1.0~1.6s` 后摇输出窗口 | 若为制空 BOSS，大招必须包含落地硬直防软锁 |
| `标志篡夺掉落` | 必产出 1 件该 BOSS 同源主题零件进入永久解锁池 | 严格遵守 `09` §4.1 隐性 BP 预算上限，绝不数值膨胀 |

### 4.2 第二卷《深渊暗海界》（2-1 ~ 2-8）长线接力规划示例
