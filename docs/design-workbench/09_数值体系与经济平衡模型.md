## 2. 核心属性基准与推导公式（已确认，P-042, P-059）

### 2.1 裸鸡属性基准（零号禁忌体初始面板）

| 属性 | 基准值 | 单位与含义 | 护栏上下限 |
|---|---|---|---|
| `HP` | `100` | 最大生命值 | 最低 `60`，首章成型约 `180 ~ 320` |
| `ATK` | `10` | 基础攻击力 | 最低 `5`，首章成型约 `22 ~ 55` |
| `DEF` | `0` | 护甲防御值 | 最低 `0`，首章成型约 `0 ~ 36` |
| `SPD` | `100` | 移动与出招敏捷基数 | 硬限制 `clamp(40, 220)` |
| `CAPACITY` | `14` | 基础负重承载力 | 随躯干 `size` 提升：`14 + 有效bodySize × 4` |

### 2.2 叠阶与躯干拼色融合折算（防溢出防膨胀核心公式）

1. **同件叠阶倍率（P-059）**：
   - `Lv.1`（基础态）：面板系数 **`1.00×`**，解锁基础通用作用；
   - `Lv.2`（发光升阶）：面板系数 **`1.35×`**，视觉高亮调色 + 3 颗环绕粒子；
   - `Lv.3`（满阶觉醒）：面板系数 **`1.75×`**，金色觉醒粒子 + **解锁该件专属 Lv.3 机制质变**（见 §4 全量表）。
   - *设计理由*：同件 `Lv.1 → Lv.3` 面板只涨 `75%` 而非翻倍，确保 60% 胜负仍由机制克制决定，避免满阶单件数值碾压。

2. **躯干 `body` 1 / 2 / 3 种拼色融合折算（防三躯干属性直接×3 崩盘）**：
   - 躯干是唯一支持异件融合的槽位（上限 3 种，P-026/P-030）。为让“单躯干轻量专精”与“2~3 拼色混搭彩蛋”都有策略价值，拼色后所有躯干件的面板增量、质量与 `size` 统一乘以**融合权重系数**：
     - **1 种躯干**：面板 × **`1.00`**，质量 × **`1.00`**，全部特性生效；
     - **2 种拼色**：两件合计面板 × **`0.65`**（总计约 `1.30×` 单躯干面板），合计质量 × **`0.80`**，双特性全生效且可触发 2 拼色彩蛋；
     - **3 种拼色**：三件合计面板 × **`0.50`**（总计约 `1.50×` 单躯干面板），合计质量 × **`0.75`**，三特性全生效且可同时触发多组拼色彩蛋。
   - *效果验算*：三拼色比单躯干多约 `50%` 躯干槽面板并白赚多重特性/彩蛋，但需投入 3 次三选一机会且背负更高总质量（容易压垮生物翼触发「太沉啦飞不动」），取舍极为清晰。

3. **面板最终推导顺序（确定性纯函数）**：
   1. 计算各槽位有效增量（躯干乘融合权重，所有部件乘对应 `LEVEL_SCALE`，四舍五入取整）；
   2. 累加基础值：`HP = 100 + Σhp`，`ATK = 10 + Σatk`，`DEF = Σdef`；
   3. 计算负重惩罚：`massRatio = clamp(totalMass / (capacity × 1.45), 0, 0.50)`；`SPD = clamp(round((100 + Σspd × 3) × (1 - massRatio)), 40, 220)`；
   4. 若拥有 `crest.crown`（黄金王冠光环），按阶数对 `HP / ATK / DEF` 乘统一光环系数（`Lv1: 1.08× / Lv2: 1.12× / Lv3: 1.16×`）；
   5. 按固定规则顺序结算 8 组特殊组合/冲突（先加值 `statAdd`，再乘区 `statMul`，最后置位 `flags`）。
   6. **物理直觉标记**：`overloaded = (totalMass > capacity)`；`grounded = !hasTrait('jet_boost') && (hasTag('grounded') || (hasTag('bio_wing') && overloaded))`；`canGlide = hasTrait('glide') && !grounded`。

## 3. 战斗伤害管线与多主动技冲突规则（已确认，P-059, P-060）

### 3.1 统一伤害结算 8 步管线（单机手操与万坤榜自动对决共用同一内核）

每次攻击判定严格按以下顺序执行，彻底消除同 tick 或多乘区歧义：

| 步序 | 结算阶段 | 精确公式 / 规则 | 护栏与反例说明 |
|---|---|---|---|
| **1** | **高度与对空命中（P-009）** | 目标离地高度 `y > 0.65m` 视为「空中态」。攻击未带 `canHitAir` 且攻击者自身不在空中（`y ≤ 0.45m`）时，直接判定 **「空中躲避」**（0 伤害，不触发命中后效） | 跳跃可躲地面近战与地面震波，但躲不开长舌/炮口/电弧/空中飞扑 |
| **2** | **闪避判定** | 仅当攻击未携带 `radar_lock` / `guaranteed_lock` 时检定。单件 `dodge` 贡献 `+14%`（Lv2 `18%` / Lv3 `22%`），多件叠加**硬上限封顶 `35%`** | 杜绝全闪避无限 Miss 的糟糕体验；雷达锅天然克制孔雀尾+兔耳闪避流 |
| **3** | **基础招式倍率** | `rawDmg = 攻击者ATK × 招式倍率 × 组合/空中增伤乘区`（普攻 `1.0×`、高频连击单段 `0.72×`、鳄鱼重咬 `1.35×`、火箭头槌 `1.85×`） | 所有外部乘区先相乘再进护甲，便于玩家口算 |
| **4** | **有效护甲与破甲** | 默认 `effDef = 目标DEF`；若携带 `armor_pierce`（螃蟹大钳/电锯/犀牛冲锋），`effDef = 目标DEF × 0.50`；中毒等真伤直接跳过步骤 4~5 | 破甲流专克乌龟壳+铁皮+重盾铁桶阵 |
| **5** | **边际递减护甲（P-059）** | **`mitigated = rawDmg × 100 / (100 + effDef × 5)`** | `DEF=10` 减伤 `33.3%`；`DEF=20` 减伤 `50%`；`DEF=40` 减伤 `66.7%`，永不归零 |
| **6** | **暴击与防御减伤** | 暴击率：基础 `10%`，`crit_boost` 提至 `25%`，`guaranteed_lock` 提至 `40%`，暴击伤害 **`1.50×`**；目标处于 `S` 键举盾格挡态时，最终伤害 **`× 0.35`**（`-65%` 减伤） | 若万坤榜进入 25s 后「巴别过载狂暴」，伤害按每秒 `+15%` 叠乘 |
| **7** | **保底与护盾吸收** | `finalDmg = max(1, round(mitigated))`；先扣除临时护盾，溢出部分再扣 `HP` | 绝不出现 `0` 伤害刮痧死循环 |
| **8** | **命中后置触发** | ① 攻击方施加中毒/减速/击退（受目标 `steady`/`iron_fortress` 抗性削减）；② 近战命中时触发受击方「刺猬反伤 / 河豚弹飞」；③ 若受击方 `HP ≤ 0` 且持有未触发的「壁虎断尾」，立即保命留 `1 HP` 并回血 `30% MaxHP`（每关限 1 次） | 反伤伤害不再二次触发双方反伤（防无限递归！） |

## 4. 36 件零件隐性点数预算全量定标表

### 4.1 隐性预算点（BP）换算标尺
为了保证 `60% 机制克制 + 40% 数值操作` 且**无任何废件或超模神装**，所有 36 件零件均按统一隐性预算点（BP）定标：
- **属性等价换算**：`1 BP = +5 HP = +0.8 ATK = +0.6 DEF = +3 SPD`；
- **品阶预算带宽**：`Tier 1 = 18 ± 2 BP`、`Tier 2 = 22 ± 2 BP`、`Tier 3 = 25 ± 2 BP`；
- **机制定价**：强力机制（对空、破甲、断尾保命、举盾、滑翔）扣除 `4 ~ 8 BP` 面板预算；高负重（`mass ≥ 6`）或负移速返还 `+2 ~ 5 BP` 面板预算。

  - 每 3 层叠加 1 条动态变异词条，保证极限玩家在 18~25 层进入高强度策略见顶区。

## 8. 平衡自检红线（供后续跑批模拟验收）
